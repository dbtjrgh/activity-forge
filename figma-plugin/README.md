> 까닭은 `_document/자동양산.md` 의 figma 절에 있습니다.


figma 안에서 **차시마다 이닝 차례와 낱말**을 뽑아 클립보드로 보냅니다.
한 호를 한 번에 훑습니다.

## 왜 있나

REST API 는 트리를 통째로 줍니다 — 차시 하나에 **1,140KB 를 받아 0.7KB 를
씁니다.** figma 는 **받은 바이트로** 한도를 매기므로 한 호를 통째로 훑는 것은
아예 못 합니다(49MB). 플러그인은 문서를 **로컬에서** 읽어서 —

| | REST (`services/forge/figma/`) | 이 플러그인 |
|---|---|---|
| 한도 | 한 호 약 41MB 를 깎음 | **0** (네트워크를 안 탄다) |
| 토큰 | `FIGMA_TOKEN` 필요 | **필요 없음** |
| 한 호 훑기 | 못 함 | 한 번에 · **약 25KB** |

**REST 길을 대신하지 않습니다.** figma 섹션 이름이 규칙과 어긋난 차시(7호 영어
기준 2개)와 figma 에 설계가 아예 없는 차시(`W4S3` 3개)는 어느 쪽으로도 못
읽습니다. 둘은 **같은 규칙을 쓰는 두 입구**입니다 — 규칙을 고치면
`electron_app/src/main/services/forge/figma/name.ts`·`read.ts` 와 이 폴더의
`code.js` 를 **같이** 고칩니다.

## 쓰는 법

**처음 한 번 (데스크톱 앱에서만 됩니다)**

1. figma **데스크톱 앱**을 엽니다 — 브라우저에는 `Development` 메뉴가 없습니다
2. 왼쪽 위 figma 메뉴 → `Plugins` → `Development` → `Import plugin from manifest…`
   - 캔버스에서 우클릭 → `Plugins` → `Development` 로도 갑니다
3. 이 폴더의 **`manifest.json`** 을 고릅니다

**쓸 때**

1. 호 파일을 엽니다 (예: `스파크온_영어 7호`)
2. `Plugins` → `Development` → **스파크온 차례 뽑기**
3. 자동으로 복사됩니다. 안 되면 칸의 글을 직접 골라 복사하세요

> 팀원에게 뿌릴 때는 조직 비공개로 퍼블리시하면 됩니다. **퍼블리시된 플러그인은
> 브라우저에서도 돕니다** — 데스크톱 앱은 **만드는 사람만** 필요합니다.

## 내놓는 것

```json
{
  "file": "스파크온_영어 7호",
  "at": "2026-09-16T…",
  "lessons": [
    {
      "code": "ENL1M07W1S3",
      "section": "7호_lv1_1주_Word Play",
      "id": "6:12317",
      "innings": 6,
      "words": ["fork", "toothbrush", "scissors", "crayon", "umbrella", "watering can"],
      "screens": [{ "id": "6:12318", "inning": 1, "at": 1, "words": [] }]
    }
  ],
  "unread": ["영어_7호_Lv1 / 트레이스 리소스 a~z (1202)"]
}
```

- **`words[i]` 가 `i+1` 번째 이닝의 낱말입니다.** 하나로 안 좁혀진 이닝은
  **`null`** 입니다 — 아무거나 고르면 여섯 자리가 통째로 한 칸씩 밀립니다
- **`unread`** 는 학습코드를 못 읽은 섹션입니다. 버리지 않고 이름 그대로
  넘깁니다 — 사람이 이름을 잘못 지은 것과 애초에 차시가 아닌 것(리소스·시안)을
  가르는 것은 사람 몫입니다
