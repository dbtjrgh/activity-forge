# SparkOn Manager 실행 파일이 막히면

SparkOn Manager 실행 파일은 코드 서명을 하지 않았습니다. 그래서 Windows 보안 기능이 실행을 막을 수 있습니다.
실행 파일과 함께 이 안내를 전달합니다(2026-10-01 결정 — 서명 대신 막히면 안내).

## 「Windows의 PC 보호」 파란 창이 뜰 때

1. 창의 **추가 정보**를 누릅니다.
2. 아래에 나온 **실행** 단추를 누릅니다.

한 번 실행하면 같은 파일은 다시 묻지 않습니다.

## 「스마트 앱 컨트롤에서 이 앱을 차단했습니다」가 뜨거나, 아무 창도 안 뜰 때

스마트 앱 컨트롤은 앱마다 허용할 수 없습니다. 이 기능을 꺼야 실행됩니다.

1. 시작 메뉴에서 **Windows 보안**을 엽니다.
2. **앱 및 브라우저 컨트롤** → **스마트 앱 컨트롤 설정**을 누릅니다.
3. **끄기**를 고릅니다.
4. 실행 파일을 다시 실행합니다.

- 회사에서 관리하는 PC라면 직접 바꾸지 말고 관리자에게 문의하세요.
- Windows 버전에 따라 한 번 끄면 다시 켜려면 Windows를 다시 설치해야 할 수 있습니다. 끄기 전에 확인 창의 설명을 읽어 보세요.

## 그 밖의 보안 프로그램(사내 보안 프로그램 등)이 막을 때

보안 프로그램 관리자에게 이 실행 파일을 예외로 등록해 달라고 요청하세요.
실행 파일을 새로 받을 때마다 파일이 달라지므로 다시 요청해야 할 수 있습니다.
앱 화면이나 기능이 바뀌는 업데이트는 앱 안의 「업데이트」 단추로 받으므로, 실행 파일을 다시 받을 일은 많지 않습니다.
