액티비티 한 편을 제작하는 순서입니다.
  1. 학습코드를 입력합니다 ex) MAL1M07W1S3
  2. 원본 회차에서 불러오기 — 동일한 모듈로 제작된 회차의 값과 리소스를 그대로 가져옵니다. 처음 사용하는 모듈이면 모듈만 선택합니다
  3. 폴더 열기 → 이미지·사운드 파일을 폴더로 옮긴 뒤 → 폴더 읽기
  4. 리소스 탭에서 파일에 별칭을 지정하고, GameData 탭에서 값을 입력합니다
  5. 우측 검증의 오류가 0 이 되면 액티비티 생성이 활성화됩니다
값과 리소스를 그대로 가져옵니다
스펙은 기존 액티비티에서 자동으로 뽑은 초안입니다.

모듈을 고르면 그 모듈을 쓰는 액티비티를 전부 읽어 GameData 의 항목·타입· 기본값을 추려 냅니다. 여러 회차에서 같은 값이면 기본값으로, 회차마다 다르면 입력 항목으로 잡습니다. 사람이 손으로 정리한 규격서가 아니라 실제 제작물에서 역으로 추출한 결과입니다.

그래서 표본에 없던 항목은 스펙에도 없습니다. 기계가 알 수 없는 제목·항목 설명·필수 여부는 비어 있으니 사람이 채워야 합니다 — 2단계에서 하는 일이 그것입니다. 채운 내용은 초안을 다시 만들어도 유지됩니다.

1모듈 고르기액티비티가 많은 것부터

모듈을 고르면 그것을 쓰는 액티비티를 다 읽어 초안을 만듭니다.

2훑어보기필수 여부만 봐 주세요

학습코드를 적으면 그 폴더를 읽습니다.

3검증적을 때마다 바로 봅니다

학습코드와 모듈을 고르면 검사합니다.
